# 學生即時文字雲

讓老師隨時更換題目，學生掃描 QR Code 後即可即時回答；重複出現的答案會自動放大。

## 線上使用

- [老師端／文字雲展示畫面](https://student-live-word-cloud.kellyhsu.chatgpt.site)
- [學生回答頁](https://student-live-word-cloud.kellyhsu.chatgpt.site/join)

## 功能

- 題目可隨時更換
- 自動產生學生回答 QR Code
- 即時彙整並顯示文字雲
- 暫停或重新開放回答
- 匯出 CSV 與 Excel
- 使用線上資料庫保存回答

> 老師端密碼未寫入 GitHub；正式網站使用獨立的安全設定。
